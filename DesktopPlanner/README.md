# DesktopPlanner — виджет-планер задач для Windows

Frameless-виджет для рабочего стола (PyQt6) с offline-first двухсторонней
синхронизацией с Google Таблицами.

## Возможности

- Живёт на рабочем столе и/или в системном трее, всегда под рукой.
- Полностью работает офлайн: SQLite — источник истины для интерфейса,
  все изменения ставятся в очередь (outbox) и отправляются в Google Sheets,
  когда появляется сеть/дойдёт очередь синхронизации.
- Разрешение конфликтов: побеждает запись с более свежим `UpdatedAt`;
  несинхронизированные локальные правки не перезатираются входящими данными.
- Вкладки **Сегодня** (с отдельным блоком "Просрочено"), **Календарь**,
  **Отменённые** (архив с восстановлением).
- Цветовая индикация дедлайнов: жёлтый (< 4 часов), красный (< 1 часа).
- Windows Toast-уведомления за настраиваемое время до дедлайна
  (без повторной отправки одного и того же уведомления).
- Компактный режим — сворачивание в тонкую полосу-счётчик (🔥/🕒).
- Настройки: тема Light/Dark/System, always-on-top, прозрачность,
  прилипание к краям экрана, автозагрузка, интервал синхронизации.
- Single-instance: повторный запуск .exe просто разворачивает уже открытое окно.

## Структура проекта

```
DesktopPlanner/
├── app/                        # Исходный код приложения
│   ├── main.py                 # Точка входа
│   ├── config.py                # Константы, настройки (JSON)
│   ├── models.py                 # Task: модель + сериализация в строку таблицы

│   ├── sync.py                   # SyncWorker/SyncThread — фоновая синхронизация
│   ├── autostart.py               # Автозагрузка и системная тема (реестр Windows)
│   ├── notifier.py                 # Windows Toast + fallback на трей
│   ├── styles.py                    # QSS темы Light/Dark
│   ├── task_card.py                  # Карточка задачи (accordion)
│   ├── settings_dialog.py             # Окно настроек
│   ├── tray.py                         # Системный трей и меню
│   ├── single_instance.py               # Защита от повторного запуска
│   ├── main_window.py                    # Главное окно
│   ├── requirements.txt                   # Зависимости для запуска
│   ├── requirements-build.txt              # + PyInstaller, для сборки
│   └── assets/icon.ico|png                 # Иконка приложения
├── sheet_template/
│   ├── generate_template.py     # Скрипт генерации шаблона таблицы
│   └── Tasks_Template.xlsx       # Готовый шаблон для импорта в Google Sheets
├── installer/
│   └── installer.iss            # Inno Setup скрипт
├── .github/workflows/
│   └── build-windows.yml        # GitHub Actions: сборка .exe на Windows-раннере
├── build.bat                    # Сборка одной кнопкой локально на Windows
├── SETUP_GOOGLE_SHEETS.md        # Инструкция по подключению Google Sheets
└── README.md                     # Этот файл
```

## Как запустить из исходников (для разработки)

```bat
cd DesktopPlanner
python -m venv .venv
.venv\Scripts\activate
pip install -r app\requirements.txt
python app\main.py
```

## Как собрать .exe и инсталлятор

**Важно:** реальный Windows `.exe`/`Setup.exe` можно собрать только на
самой Windows (PyInstaller использует нативные библиотеки ОС, под которую
собирает). Ниже — два способа получить готовый инсталлятор.

### Вариант А — локально на своём Windows-компьютере

Требуется один раз установить:
1. [Python 3.10+](https://www.python.org/downloads/) (отметить "Add to PATH"
   при установке).
2. [Inno Setup 7](https://jrsoftware.org/isdl.php#v7) (рекомендуется 64-битная редакция).

Затем просто запустить `build.bat` двойным щелчком из корня проекта.
Скрипт сам создаст виртуальное окружение, поставит зависимости, соберёт
`.exe` через PyInstaller и упакует его в инсталлятор через Inno Setup.

Результат:
- `dist\DesktopPlanner\DesktopPlanner.exe` — портативная версия.
- `dist_installer\DesktopPlanner_Setup.exe` — полноценный инсталлятор.

### Вариант Б — автоматически через GitHub Actions (ничего не ставить у себя)

1. Создайте репозиторий на GitHub и запушьте туда содержимое этой папки.
2. Откройте вкладку **Actions** в репозитории — воркфлоу `Build Windows EXE
   and Installer` запустится автоматически при пуше (или запустите его
   вручную кнопкой "Run workflow").
3. Через несколько минут в разделе **Artifacts** появится готовый
   `DesktopPlanner_Setup.exe` — скачайте и запустите на своём Windows.
4. Если запушить git-тег вида `v1.0.0`, инсталлятор дополнительно
   прикрепится к GitHub Release.

## Подключение к Google Таблицам

См. подробную пошаговую инструкцию в [SETUP_GOOGLE_SHEETS.md](SETUP_GOOGLE_SHEETS.md).

Кратко: создать проект в Google Cloud → включить Sheets API и Drive API →
создать сервисный аккаунт → скачать `credentials.json` → расшарить таблицу
на email сервисного аккаунта с правами Editor → указать путь к файлу и
ID/ссылку таблицы в настройках виджета.

Готовый шаблон таблицы (с правильными заголовками, примерами и выпадающими
списками Status/Priority) лежит в `sheet_template/Tasks_Template.xlsx` —
импортируйте его в новую Google Таблицу через **Файл → Импортировать**.

## Формат листа Tasks

| Столбец | Тип | Описание |
|---|---|---|
| ID | UUID | Первичный ключ, генерируется на клиенте |
| Title | text | Название задачи |
| Description | text | Подробное описание |
| StartDate | YYYY-MM-DD | Начало |
| DeadlineDate | YYYY-MM-DD | Дедлайн (дата) |
| DeadlineTime | HH:MM | Дедлайн (время); пусто → трактуется как 23:59 |
| Status | Active/Completed/Canceled | Статус (пусто → Active) |
| Priority | High/Medium/Low | Приоритет (пусто → Medium) |
| Assignee | text | Ответственный (необязательно) |
| UpdatedAt | ISO-8601 | Для разрешения конфликтов при синхронизации |

Сопоставление столбцов — **по имени заголовка**, а не по позиции: можно
менять местами колонки в таблице, лишь бы названия в первой строке совпадали
буквально с приведёнными выше.
