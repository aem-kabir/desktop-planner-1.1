# Подключение планера к Google Таблицам

Это пошаговая инструкция для человека, который никогда не работал с Google Cloud.
Весь процесс делается один раз, займёт 10–15 минут.

## Что такое credentials.json и зачем он нужен

`credentials.json` — это файл-ключ **сервисного аккаунта** Google. Сервисный
аккаунт — это как отдельный "робот-пользователь" Google, который умеет заходить
в Google Таблицы сам, без открытия браузера и без ввода вашего логина/пароля.

Файл `credentials.json` содержит секретный ключ этого робота. Приложение
использует его, чтобы каждый раз при синхронизации "представляться" Google
от имени этого робота и получать доступ к таблице. Вы указываете путь к этому
файлу один раз в настройках приложения — дальше всё происходит автоматически,
без каких-либо повторных логинов.

**Важно:** храните `credentials.json` в надёжном месте и не публикуйте его
(например, не выкладывайте в открытый репозиторий на GitHub) — тот, у кого
есть этот файл, получает доступ к таблицам, которыми вы поделились с этим
сервисным аккаунтом.

## Шаг 1. Создать проект в Google Cloud

1. Откройте <https://console.cloud.google.com/>.
2. Войдите под своим обычным Google-аккаунтом (тем же, где лежит ваша таблица,
   или любым другим — не важно).
3. Вверху страницы нажмите на выпадающий список проектов → **"Новый проект"**.
4. Введите название, например `DesktopPlanner`, и нажмите **"Создать"**.
5. Дождитесь уведомления о создании и переключитесь на этот проект (тот же
   выпадающий список вверху).

## Шаг 2. Включить Google Sheets API и Google Drive API

1. В меню слева (☰) откройте **"API и сервисы" → "Библиотека"**.
2. В поиске введите `Google Sheets API`, откройте найденный результат и
   нажмите **"Включить"**.
3. Вернитесь в библиотеку, найдите `Google Drive API`, откройте и тоже нажмите
   **"Включить"**.

(Drive API нужен, чтобы сервисный аккаунт мог находить таблицу по ссылке/ID.)

## Шаг 3. Создать сервисный аккаунт

1. В меню слева откройте **"IAM и администрирование" → "Сервисные аккаунты"**.
2. Нажмите **"Создать сервисный аккаунт"**.
3. Укажите имя, например `desktop-planner-bot`, нажмите **"Создать и
   продолжить"**.
4. На шаге "Роль" можно ничего не выбирать (пропустить) — нажмите
   **"Продолжить"**, затем **"Готово"**.

## Шаг 4. Скачать credentials.json (ключ сервисного аккаунта)

1. В списке сервисных аккаунтов откройте только что созданный.
2. Перейдите на вкладку **"Ключи" (Keys)**.
3. Нажмите **"Добавить ключ" → "Создать новый ключ"**.
4. Выберите тип **JSON** и нажмите **"Создать"**.
5. Файл `credentials.json` (или с похожим длинным именем) автоматически
   скачается на компьютер. Переименуйте его при желании в `credentials.json`
   и сохраните в удобное место, например
   `%LocalAppData%\DesktopPlanner\credentials.json`.

## Шаг 5. Поделиться таблицей с сервисным аккаунтом

Сервисный аккаунт имеет свой собственный email, похожий на:

```
desktop-planner-bot@your-project-id.iam.gserviceaccount.com
```

Найти его можно на той же странице сервисного аккаунта (поле "Email") или
внутри самого файла `credentials.json` (поле `"client_email"`).

1. Откройте вашу Google Таблицу (или создайте новую и импортируйте туда
   `Tasks_Template.xlsx` из этого проекта: **Файл → Импортировать → Загрузить**).
2. Нажмите кнопку **"Настройки доступа" / "Share"** в правом верхнем углу.
3. Вставьте email сервисного аккаунта, выберите роль **"Редактор" (Editor)**
   и нажмите **"Отправить"** / **"Готово"**.

Без этого шага приложение не сможет ни читать, ни записывать в таблицу —
даже с правильным `credentials.json`.

## Шаг 6. Узнать Spreadsheet ID (или просто скопировать ссылку)

Приложение принимает **и полный URL, и чистый ID** — можно просто
скопировать ссылку из адресной строки браузера, когда таблица открыта:

```
https://docs.google.com/spreadsheets/d/1AbCдлинный_идентификатор_XyZ/edit#gid=0
```

## Шаг 7. Ввести данные в настройках виджета

1. Откройте планер → **Настройки → Google Sheets**.
2. **credentials.json** — укажите путь к скачанному файлу (кнопка "Обзор…").
3. **Spreadsheet ID / ссылка** — вставьте скопированную ссылку целиком или
   чистый ID.
4. **Название листа** — впишите `Tasks` (или как называется ваш лист,
   если вы его переименовали).
5. Нажмите **"Проверить подключение"** — должно появиться "✅ Подключение
   успешно". Если ошибка — чаще всего это значит, что таблица не расшарена
   на email сервисного аккаунта (Шаг 5), либо не включён один из API
   (Шаг 2).
6. Нажмите **"Сохранить"**.

Готово — дальше синхронизация происходит автоматически, в фоне, с
интервалом, который можно настроить (вкладка "Система").
